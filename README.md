# Áurea Estética Avançada — landing page

Landing page conceitual de uma clínica de estética premium (marca fictícia). Página única em HTML/CSS/JS, sem build.

- Abrir localmente: sirva a pasta com qualquer servidor estático e acesse `index.html`.
- Placeholders a trocar antes de usar com cliente real: WhatsApp/telefone `5511900000000`, domínio `aureaestetica.com.br` (canonical/OG/JSON-LD), `CRBM 00000`, nome da especialista e depoimentos.
- Indexação desligada (`noindex` + `robots.txt`) enquanto for proposta.
- Fotos: Unsplash (licença Unsplash).
